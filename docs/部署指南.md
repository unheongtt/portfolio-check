# 部署指南

产品 URL 与仓库地址提交于「URL及源代码」表单。以下为 Render 部署步骤（与链析 ChainLens 同款）。

## 一、Render 部署（推荐：Blueprint 一键）

1. 仓库已含 `render.yaml` 蓝图与 `Dockerfile`。
2. 登录 Render → **New + → Blueprint** → 选择 GitHub 仓库 `unheongtt/portfolio-check`。
3. 蓝图自动创建 Web Service（Docker runtime，`/api/health` 健康检查）。
4. 在服务的 **Environment** 中填入 `FUYAO_API_KEY`（`sync: false` 的字段需手动填；`IFIND_*`/`LLM_*` 可选）。
5. 部署完成后，打开服务 URL 即可体验。

## 二、手动部署（同链析 ChainLens）

1. GitHub 新建仓库，推代码：
   ```bash
   git init && git add . && git commit -m "持仓体检 PortfolioCheck v0.1"
   git branch -M main
   git remote add origin https://github.com/unheongtt/portfolio-check.git
   git push -u origin main
   ```
2. Render → **New + → Web Service** → 选择该仓库，Runtime 选 **Docker**。
3. Environment 填入 `FUYAO_API_KEY`（必填，体验估值/相关性/波动三维）、`FUYAO_BASE_URL`（默认 `https://fuyao.aicubes.cn`）。
4. Health Check Path 设为 `/api/health`。

## 三、环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `FUYAO_API_KEY` | 是（体验完整五维） | 扶摇 API Key |
| `FUYAO_BASE_URL` | 否 | 默认 `https://fuyao.aicubes.cn` |
| `IFIND_MCP_URL` / `IFIND_MCP_TOKEN` | 否 | iFinD MCP（港美股/宏观补充） |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | 否 | 缺省走规则模板解读 |

> 安全：`FUYAO_API_KEY` 等凭证只放 Render 环境变量，**绝不提交仓库**（`.gitignore` 已排除 `.env`，`test_compliance.py` 断言健康接口不回传密钥值）。
