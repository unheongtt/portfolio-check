# 测试说明

运行：`uv run pytest -q`（当前 **30 个用例**，全部通过）。测试默认在**无凭证环境**下运行（`conftest.py` 注入空 Key），专门验证「显式失败、不静默兜底」。

## 覆盖矩阵（对应题目要求：主链路 / 数据缺失与接口失败 / 合规边界）

| 要求 | 测试类 | 关键断言 |
|---|---|---|
| **主链路** | `test_risk_engine.py` | 五类风险口径：单标的/前三大集中度阈值、相关系数（含 Pearson=1 精确断言）、PE/PB 极端与负 PE、年化波动率、概念扎堆；diversified 组合不误报 |
| **主链路（API）** | `test_main_pipeline.py` | 示例组合 6 只且权重=100；`/api/check` 返回 report 且五类维度全部覆盖；报告落库可 `GET /api/reports/{id}` 回读；404 处理 |
| **数据缺失/接口失败** | `test_main_pipeline.py::test_check_no_fake_numbers_without_key` | 无凭证时：估值/相关性/波动**显式报「数据不足」**（uncertain + note），集中度/题材暴露仍可计算；任何非 ok 状态证据 `value is None` |
| **合规：不荐股不预测** | `test_compliance.py::TestNoAdvice` | 全链路文本不含「买入/卖出/目标价/看涨/必涨/抄底/收益承诺」等 14 类违禁词 |
| **合规：数字可追溯** | `test_compliance.py::TestNumberProvenance` | 每个证据带 `source`；ok 状态必有 `value`+`caliber`；非 ok 状态 `value is None`（至少 3 个显式失败数据点） |
| **合规：AI 待复核** | `test_compliance.py::TestAITraceability` | 每项解读 + 整体摘要 `review_status=pending` 且带 `ai_output_id`；产出落库 `ai_output` 可追溯；无 Key 时 engine=rules |
| **合规：不泄露凭证** | `test_compliance.py::TestNoCredentialLeak` | 健康接口只返回 name/configured/status/message，不回传密钥值；`.gitignore` 排除 `.env` |

## 关键设计决策

1. **「失败不兜底」用断言写死**：`test_failure_status_never_fake` / `test_check_no_fake_numbers_without_key` 断言 `data_status != ok ⇒ value is None`。这是产品合规底线——任何状态下都不允许「看起来正常」的数字。
2. **AI 不生成数字**：风险引擎（`risk/engine.py`）是纯函数、零 I/O、无 LLM，全部数值来自确定性计算与结构化数据源；AI 层（`ai/analyzer.py`）只做「读与讲」。
3. **无凭证也能跑通部分维度**：集中度/题材暴露只依赖「用户输入权重 + 种子行业/概念」，无需任何凭证即可出结论；估值/相关性/波动在无凭证时显式降级为「数据不足」，不做静默省略。
4. **测试隔离**：`conftest.py` 在导入 app 前注入 `DB_PATH`/`SEED_DIR`（pydantic-settings 按字段名大写匹配，非 `PORTFOLIO_*` 前缀），使用独立 `test_portfolio.db`，会话级重建清理。
5. **已知限制**：前端为静态 SPA，未配置浏览器 E2E（Playwright），属未做事项；API 层与风险引擎已由 pytest 全覆盖。

## 异常场景清单（与前端 data_status 徽标一一对应）

| 场景 | 模拟方式 | 预期呈现 |
|---|---|---|
| 未配置扶摇 Key | 环境默认 | 估值/相关性/波动维度 → `missing` 徽标 + 「数据不足，需扶摇 Key」 |
| Key 失效（2001）/ 无权限（2003） | `SourceError(auth/permission)` | 维度级 `error` + 业务码说明 |
| 超时 / 网络错误 | `SourceError(timeout/network)` | `error` + 原因 |
| 限流（429） | `SourceError(rate_limit)` | `error` + 「触发限流」 |
| 上游 schema 变化 | item 非列表 | 不崩溃 → 显式 `missing`/`error` |
| 历史日线不足 | 少于 20 交易日 | 相关性/波动 → `uncertain` 「数据不足」 |
| 权重和不等于 100% | `POST /api/check` | HTTP 400 显式拒绝 |
